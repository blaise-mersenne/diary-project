# Epic 01 — 하이브리드 감정 입력 시스템 (Hybrid Emotion Input UX)

> **상태:** 초안 (Draft)  
> **최종 수정일:** 2025-07

---

## 개요

앱 진입 시 유저가 **최소한의 노력**으로 자신의 긍정적 감정을 기록할 수 있도록 설계된 입력 시스템.  
글쓰기 부담을 제거하고, 탭 몇 번만으로 기록이 완료되는 경험을 목표로 한다.

---

## 기능 명세

### 1. 프리셋 칩 (Preset Chips)

- 앱 진입 시, 보편적인 긍정 감정 단어(예: `편안한`, `상쾌한`, `다행인` 등) **10~15개**를 칩(Chip) 형태로 제공
- 유저가 **최소 2개 이상** 탭 하도록 유도
- 칩 선택 후 **선택적 메모 입력창** 제공 (입력 강제 없음)

### 2. 검색 및 커스텀 추가 (Search & Create)

- 원하는 단어가 프리셋에 없을 경우 **검색 기능** 지원
- 검색 결과가 없을 경우, 유저가 입력한 텍스트 그대로 **새로운 감정 칩을 생성**할 수 있도록 지원

### 3. 데이터 플라이휠 (Data Flywheel)

- 유저들이 직접 생성한 커스텀 감정 단어를 **수집 및 분석**
- 사용 빈도가 높은 단어는 시스템의 **기본 프리셋 칩으로 자동 승격**
- 서비스 전체 유저 데이터 기반으로 프리셋이 점진적으로 개선되는 구조
