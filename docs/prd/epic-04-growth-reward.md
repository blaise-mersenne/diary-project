# Epic 04 — 성장 및 보상 시스템 (Growth & Reward Loop)

> **상태:** 초안 (Draft)  
> **최종 수정일:** 2025-07

---

## 개요

즉각적 보상 대신 **'지연된 성장'** 을 통해 자연스러운 재방문을 유도하는 보상 루프.  
단순한 게임 메커니즘이 아닌, **감정 소화**라는 스토리텔링으로 포장하여 서비스 철학과 일치시킨다.

---

## 기능 명세

### 1. 지연된 보상 (Time-gated Growth)

- 감정 기록 시, 식물이 **즉각적으로 자라지 않음**
- 식물이 뿌리를 내리는 데 필요한 **대기 시간** 부여
  - 최소: 5분
  - 최대: 24시간
- 대기 시간 경과 후 성장 확인을 위해 앱을 재방문하도록 자연스럽게 유도

### 2. 메타포(Metaphor) 스토리텔링

- 대기 시간을 단순한 쿨타임(Cooldown)으로 표현하지 않음
- **"나의 감정이 충분히 소화되고, 씨앗이 물을 머금는 시간"** 으로 스토리텔링
- 서비스 전체 어조(Tone of Voice)와 일관되게 유지

## 확정된 디자인 스펙 (2026-05 논의 반영)

- [x] **식물 성장 단계:** 7단계 이상 (씨앗 → 새싹 → 줄기 → 봉오리 → 첫 개화 → 만개 → 씨앗 산포)
- [x] **대기 중 시각 연출:** 은은한 빛 입자(반딧불/별빛 느낌) 애니메이션 — 정적 이미지로는 표현 한계 있음, 실제 개발 시 Lottie 또는 파티클 시스템으로 구현 필요

## 기술 스택 검토 사항 (Tech Stack)

> **배경:** 식물 성장 애니메이션 및 파티클 연출 품질이 핵심 경험에 직결됨.

### MVP 단계 — 일반 앱 프레임워크 (React Native / Flutter)
- Lottie 애니메이션으로 성장 단계 전환 및 빛 입자 연출 구현
- 프레임 단위 일러스트 전환으로 성장 표현 가능
- 개발 난이도 낮음, 빠른 출시 가능

### 고도화 단계 — Unity 전환 검토
- 파티클 시스템으로 빛 입자 연출 품질 대폭 향상
- 성장 애니메이션의 유기적 표현 극대화
- **Unity Personal 플랜: 연 매출 2.7억 원 이하 무료 사용 가능**
- 런타임 수수료(설치당 과금)는 2024년 완전 폐지됨 — 라이선스 리스크 없음

### 결정 원칙
> **MVP는 일반 앱으로 먼저 출시 → 애니메이션 품질이 실제 유저 경험에서 병목으로 확인될 경우 Unity 전환 검토**
