## 1. 프로젝트 개요 (Overview)

| 항목 | 내용 |
|------|------|
| **프로젝트명** | 다이어리 프로젝트 (가칭) |
| **서비스 정의** | 성취와 생산성의 압박에서 벗어나, 순수한 긍정적 감정에 집중하게 만드는 **초저마찰(Low-Friction) 감정 기록** 및 **반려 식물(정원) 성장** 플랫폼 |
| **타겟 유저** | 번아웃이나 무기력증을 겪고 있거나, 일상의 작고 긍정적인 순간들을 수집하여 심리적 안정감을 얻고자 하는 현대인 |

---

## 2. 기획 배경 및 목표 (Background & Goals)

### 기획 배경

- 현대인들은 '성취, 의미, 생산성'에 매몰되어 자신의 순수한 감정(즐거움, 편안함 등)을 돌보지 못하는 경향이 있음.
- 기존의 아날로그 다이어리는 디지털 환경에서 지속성이 떨어지며, 일반 메모 앱은 지속적인 기록을 위한 동기부여가 부족함.

### 프로덕트 목표

글쓰기의 부담을 완벽히 없애고 **게이미피케이션(Gamification)** 을 결합하여, 유저가 매일 자신의 긍정적 감정을 들여다보고 기록하는 **습관 형성**을 유도한다.
