# Epic 05 — 비즈니스 모델 (Monetization)

> **상태:** 초안 (Draft)  
> **최종 수정일:** 2025-07

---

## 개요

**핵심 가치(감정 기록)는 전면 무료**로 제공하되,  
**'시간 단축'** 과 **'꾸미기'** 영역에 수익 모델을 집중한다.

---

## 인앱 재화 시스템 — 💧 물방울 (2026-05 확정)

> 별도 게임 재화 **'물방울'** 을 도입하여 현금 결제의 심리적 저항을 낮추는 2단계 구조.  
> "식물에 물을 준다"는 서비스 메타포와 자연스럽게 연결됨.

### 물방울 획득 방법

| 방법 | 설명 |
|------|------|
| **현금 구매** | 물방울 패키지를 앱스토어 인앱 결제로 구매 |
| **광고 시청** | 보상형 광고 시청 시 소량 물방울 지급 |
| **감정 기록** | 매일 감정을 기록할 때마다 소량 물방울 자동 지급 → 기록 습관 강화와 연동 |

> 💡 **기록 → 물방울 획득 → 정원 꾸미기 → 더 기록하고 싶어짐** 의 선순환 구조로 PRD 핵심 가치(긍정 강화 루프)와 일치함.

### 물방울 사용처

| 카테고리 | 설명 |
|----------|------|
| **공간 확장** | 정원 슬롯 확장 (기본 화분 → 더 넓은 정원) |
| **희귀 씨앗** | 희귀/전설 등급 꽃·식물 씨앗 구매 → 수집욕 자극 |
| **정원 장식 아이템** | 나무 벤치, 돌 랜턴, 작은 분수 등 오브젝트 구매 |
| **특수 날씨 이펙트** | 오로라 밤하늘, 별빛 정원, 황금빛 노을 등 |

---

## 수익 모델

### 1. 보상형 광고 (Rewarded Ads)

- 적용 시점 1: 식물 성장 **대기 중** — 광고 시청 시 대기 시간 즉시 완료 (→ Epic 04 참고)
- 적용 시점 2: 물방울 **무료 획득** 수단으로도 활용
- 특징: 강제 광고 없음. 유저가 원할 때만 선택하는 구조로, 서비스 철학(긍정 강화)과 충돌하지 않음

### 2. 인앱 결제 (In-App Purchases)

- 물방울 패키지를 현금으로 구매하는 방식
- 아이템을 직접 현금으로 구매하는 방식은 사용하지 않음
- 물방울 가격 체계 및 패키지 구성은 추후 확정 (→ 미결 사항 참고)

---

## 설계 원칙

> **"돈을 내지 않아도 핵심 경험은 동일하게 즐길 수 있어야 한다."**

- 무료 유저와 유료 유저의 **감정 기록 경험은 동일**하게 유지
- 유료 아이템은 기능적 우위가 아닌 **심미적·수집적 가치**에 집중
- 광고는 항상 **선택적(Opt-in)** 으로만 제공
- 기록만 꾸준히 해도 물방울이 쌓여 무료로 아이템을 획득할 수 있는 구조 유지
