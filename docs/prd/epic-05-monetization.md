# Epic 05 — 비즈니스 모델 (Monetization)

> **상태:** 초안 (Draft)  
> **최종 수정일:** 2025-07

---

## 개요

**핵심 가치(감정 기록)는 전면 무료**로 제공하되,  
**'시간 단축'** 과 **'꾸미기'** 영역에 수익 모델을 집중한다.

---

## 수익 모델

### 1. 보상형 광고 (Rewarded Ads)

- 적용 시점: 식물 성장 **대기 중** (→ Epic 04 참고)
- 방식: 짧은 동영상 광고를 **자발적으로** 시청하면 대기 시간을 즉시 완료(해금)
- 특징: 강제 광고 없음. 유저가 원할 때만 선택하는 구조로, 서비스 철학(긍정 강화)과 충돌하지 않음

### 2. 인앱 결제 (In-App Purchases)

| 카테고리 | 설명 |
|----------|------|
| **공간 확장** | 기본 화분을 넘어, '내 정원 크기 늘리기(슬롯 확장)' 기능 판매 |
| **프리미엄 씨앗** | 다채롭고 희귀한 새로운 꽃/식물 씨앗 판매 → 유저의 수집욕 자극 |
| **정원 장식 아이템** | 정원을 꾸밀 수 있는 오브젝트 아이템 판매 |
| **특수 날씨 이펙트** | 일반 날씨 외 특별한 시각 이펙트(예: 오로라, 별빛 등) 판매 |

---

## 설계 원칙

> **"돈을 내지 않아도 핵심 경험은 동일하게 즐길 수 있어야 한다."**

- 무료 유저와 유료 유저의 **감정 기록 경험은 동일**하게 유지
- 유료 아이템은 기능적 우위가 아닌 **심미적·수집적 가치**에 집중
- 광고는 항상 **선택적(Opt-in)** 으로만 제공
