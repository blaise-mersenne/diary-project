# Epic 03 — 감정의 시각화 아카이빙 (Visual Archive)

> **상태:** 초안 (Draft)  
> **최종 수정일:** 2025-07

---

## 개요

단순한 캘린더 조회를 넘어, 유저가 한 달 동안 수집한 긍정 단어들이 모여  
**아름답게 만개한 정원**으로 표현되는 감정 아카이브 기능.

---

## 기능 명세

### 1. 이달의 정원 뷰 (Monthly Garden View)

- 한 달 동안 기록한 긍정 감정 단어들이 **시각적으로 집약된 정원 형태**로 표현
- 많이 기록할수록 정원이 풍성하게 만개하는 구조
- 단순 텍스트 목록이 아닌, **시각적 아름다움** 자체가 조회의 목적이 되도록 설계

### 2. 심리적 위안 설계

- 유저가 앱을 열어보는 것만으로도 **무해하고 평화로운 심리적 위안**을 얻을 수 있도록 연출
- 과거 기록이 누적될수록 정원이 더욱 풍요롭게 보이는 구조 → 지속 사용 동기 강화

- [x] **감정 단어 ↔ 꽃/색상 매핑:** 감정 카테고리별 특정 꽃 종류 및 색상 연결
  - 고요한, 편안한 → 라벤더 / 흰 코스모스
  - 설레는, 기쁜 → 해바라기 / 금잔화 (골든/앰버)
  - 다행인, 감사한 → 벚꽃 / 연핑크 모란
  - 상쾌한, 활기찬 → 은방울꽃 / 흰 재스민 (민트 톤)
  - 뿌듯한 → 코랄 달리아 / 진한 장미

## 기술 스택 검토 사항 (Tech Stack)

> **배경:** 정원 뷰의 원근감/깊이감 표현 수준에 따라 개발 프레임워크 선택이 달라짐.

### MVP 단계 — 일반 앱 프레임워크 (React Native / Flutter)
- 2D 레이어 분리로 원근감을 간접 표현
- Lottie 애니메이션으로 꽃 피는 연출 구현
- 개발 난이도 낮음, 빠른 출시 가능

### 고도화 단계 — Unity 전환 검토
- 전경/중경/배경 레이어 분리로 실제 정원 깊이감 구현 가능
- 파티클 애니메이션 품질 대폭 향상
- **Unity Personal 플랜: 연 매출 2.7억 원 이하 무료 사용 가능**
- 런타임 수수료(설치당 과금)는 2024년 완전 폐지됨 — 라이선스 리스크 없음

### 결정 원칙
> **MVP는 일반 앱으로 먼저 출시 → 정원 뷰 깊이감이 실제 유저 경험에서 병목으로 확인될 경우 Unity 전환 검토**
