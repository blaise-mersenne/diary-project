# Epic 03 — 감정의 시각화 아카이빙 (Visual Archive)

> **상태:** 초안 (Draft)  
> **최종 수정일:** 2025-07

---

## 개요

단순한 캘린더 조회를 넘어, 유저가 한 달 동안 수집한 긍정 단어들이 모여  
**아름답게 만개한 정원**으로 표현되는 감정 아카이브 기능.

---

## 기능 명세

### 1. 이달의 정원 뷰 (Monthly Garden View)

- 한 달 동안 기록한 긍정 감정 단어들이 **시각적으로 집약된 정원 형태**로 표현
- 많이 기록할수록 정원이 풍성하게 만개하는 구조
- 단순 텍스트 목록이 아닌, **시각적 아름다움** 자체가 조회의 목적이 되도록 설계

### 2. 심리적 위안 설계

- 유저가 앱을 열어보는 것만으로도 **무해하고 평화로운 심리적 위안**을 얻을 수 있도록 연출
- 과거 기록이 누적될수록 정원이 더욱 풍요롭게 보이는 구조 → 지속 사용 동기 강화
